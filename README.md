# SVGator challenge assets

Images used by the Persiana template (an SVGator animation template made for
the SVGator x Contra challenge, October 2026) by [Red Mage](https://redmage.cc).

- `persiana/*-shutter.jpg`: closed shop shutters, the template's `shutter-art` slot
- `persiana/*-product.jpg`: product shots, the template's `product-image` slot

All images were generated with AI (Gamma) for this template. There is no
stock photography and no third-party artwork. They are released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/): use them
for anything, no attribution needed.
